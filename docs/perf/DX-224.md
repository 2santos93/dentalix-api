# DX-224 · «¿Quién llama?» con 60.000 pacientes

Criterio: la búsqueda por teléfono responde en menos de 300 ms con 60.000
pacientes y usa el índice `patients_tenant_phone_e164_idx` (E.164 completo,
nunca un sufijo).

## Reproducir

Contra una base desechable (`CREATE DATABASE dx224_test TEMPLATE dentalix`,
con las migraciones aplicadas y el `.env.test` apuntando a ella):

```
docker exec -i dentalix-pg psql -U dentalix -d dx224_test -v ON_ERROR_STOP=1 < test/perf/dx224-seed.sql
set -a && . ./.env.test && set +a
BENCH_RUNS=30 npx ts-node --transpile-only test/perf/dx224-bench.ts
```

El script imprime el `EXPLAIN (ANALYZE, BUFFERS)` de la consulta de
coincidencias bajo RLS (rol `dentalix_app`) y una línea JSON con la mediana y el
p95 del caso de uso entero. Sale con código 1 si no usa el índice, si el p95 es
de 300 ms o más, o si no encuentra los 3 pacientes del grupo familiar sembrado.

## Resultado (2026-11-04, portátil con la carga en 17–20)

- Plan: `Index Scan using patients_tenant_phone_e164_idx`, 0,1 ms de ejecución.
- Caso de uso entero (sede, coincidencias, citas, saldo y alertas): mediana
  18 ms, p95 116 ms (30 corridas tras una de calentamiento).
